## Overview

GC-MS chromatograms acquired in different batches of the same study drift in retention
time, so the same compound elutes at different times. `gcmsalign` aligns whole batches at once
with a transformer that predicts one monotone time warp per sample:

1. **Pretraining.** `ChromaWarpTransformer` is pretrained on synthetic GC-MS
   chromatograms with known warps. No real data is used.
2. **Anchors.** At test time, a handful of *anchors* (the same compound found in both
   batches by matching mass spectra) are extracted automatically.
3. **Calibration.** The model is calibrated on those anchors for a few hundred gradient
   steps.
4. **Evaluation.** Total-ion-chromatogram (TIC) correlation is used only to evaluate.
   It never supervises the model, unlike correlation-optimised warping (COW), which
   maximises the very metric it is scored on.

The repository contains the method, the baselines (COW-TIC, icoshift, and PCHIP through the
same anchors), and every experiment and figure of the paper, as a tested Python package.

## Data availability

**The code is open source (MIT). The data is private and will not be shared.**

The fish-oil GC-MS data used in the paper belongs to the project's data holders and is not
included in this repository, nor available on request from the authors. `data/` is excluded
from version control. Everything else is public:
- the code;
- the tests, which run on synthetic data;
- the pretraining pipeline, which uses the public MoNA and MassBank spectral libraries.

To apply the method to **your own** data, write it in the format described in
[Using your own data](#using-your-own-data).

## Getting started

### Requirements

- Python 3.11 or newer
- PyTorch 2.x (CPU is enough; CUDA and Apple MPS are supported)
- numpy, scipy, scikit-learn, matplotlib, h5py, requests (installed automatically)

### Install

```bash
git clone https://github.com/woodRock/alignment.git
cd alignment
python3.11 -m pip install -e ".[dev]"        # the package, plus pytest, coverage, ruff, mypy
```

### Check the installation

```bash
python3.11 -m pytest -m "not slow"           # ~10 s, synthetic data only
```

### A minimal example

```python
from gcmsalign import evaluation
from gcmsalign.anchors import extract_anchors
from gcmsalign.calibration import batch_tensors, calibrate, load_model, pick_device, predict
from gcmsalign.config import Paths
from gcmsalign.data import load_batch

paths = Paths()                                   # or Paths(Path('/my/project'))
a = load_batch('batch_sep2015', paths.fish_oil)
b = load_batch('batch_jul2016', paths.fish_oil)

anchors = extract_anchors(a.chromas, b.chromas, a.tic_raw, b.tic_raw).anchors
device = pick_device('cpu')
model = load_model(paths.default_ckpt, device)
x, study_ids = batch_tensors(a.chromas, b.chromas, device)
calibrate(model, x, study_ids, anchors, seed=0)
aligned, warps = predict(model, x, study_ids)     # aligned [N, T, M], warps [N, T]

print(evaluation.warped_pair(a, b, warps, aligned).mean)   # mean TIC r after alignment
```

### Using your own data

Put each batch under `data/fish_oil/<batch_name>/chroma/`, one `.npz` per sample, with:

| Array | Shape | Contents |
|---|---|---|
| `chroma` | `[200, 1000]` float32 | per time bin, the mass spectrum (m/z 0–999, 1 Da), square-rooted and L2-normalised |
| `tic_raw` | `[200]` float32 | per time bin, the summed raw intensity of that spectrum |

Time bins are 0.225-min windows on a fixed 0–45 min grid (bin *i* covers
[0.225 *i*, 0.225 (*i* + 1)) min). Step 03 produces this format from the per-run text
exports used here (`--raw-dir`); for other formats, write the two arrays directly. The batch names
and pairs used by the paper are in `src/gcmsalign/config.py`.

## Running the pipeline

Each step is a module in `gcmsalign.steps` with a numbered entry point in `scripts/`. They are
numbered in run order; each depends only on lower-numbered steps. Every script takes
`--help`, and `--root DIR` to work in a directory other than the repository.

| Step | Script | What it does | Needs |
|---|---|---|---|
| 01 | `01_download_pretrain_data.py` | Builds the EI-MS spectral library (MoNA, MassBank) for pretraining | internet |
| 02 | `02_train_warp_transformer.py` | Pretrains the WarpTransformer on synthetic warps (~15 min on an M2) | 01 |
| 03 | `03_preprocess_fish_oil_batches.py` | Raw exports → time-binned `chroma` + `tic_raw` per batch | raw data |
| 04 | `04_audit_fish_oil_samples.py` | Accounts for every sample; audits each run's time axis | raw data |
| 05 | `05_literature_baselines.py` | COW-TIC and icoshift on one batch pair | 03 |
| 06 | `06_align_testtime_calib.py` | WarpTransformer + anchor calibration on one pair and seed | 02, 03 |
| 07 | `07_pchip_pooled_anchors.py` | PCHIP through the same anchors, all pairs | 05, 06 |
| 08 | `08_ablate_pretrain.py` | Pretrained vs random-init calibration, one pair and seed | 02, 03 |
| 09 | `09_mechanism_ablation.py` | Where the gain over a spline comes from | 02, 03 |
| 10 | `10_heldout_anchor_error.py` | Leave-one-anchor-out retention-time error | 02, 03 |
| 11 | `11_within_batch_ceiling.py` | Within-batch TIC r: an upper reference for TIC r | 03 |
| 12 | `12_significance_tests.py` | Paired Wilcoxon tests with Holm correction, across seeds | 05–07 |
| 13 | `13_aggregate_seeds.py` | Mean ± s.d. over seeds for the tables | 05–08 |
| 14 | `14_generate_figures.py` | The paper's figures | 05–07 |

For example, one pair at seed 0:

```bash
python3.11 scripts/02_train_warp_transformer.py                       # → checkpoints/warp_transformer_v2.pt
P="--study-a fish_oil/batch_sep2015 --study-b fish_oil/batch_jul2016"
python3.11 scripts/05_literature_baselines.py $P
python3.11 scripts/06_align_testtime_calib.py $P --seed 0 --device cpu
```

The full set of commands for the paper (four pairs × five seeds, ablations, figures; about
8–10 hours on an Apple M2) is in [`run.md`](run.md). Analysis steps default to
`--device cpu`, which is bit-reproducible under a seed. MPS and CUDA are faster but not
bit-reproducible.

## Method

### Anchors

Anchors are found in four stages:

1. **Peaks.** Local maxima of the raw TIC above its 80th percentile, at least 5 bins apart;
   the 30 highest are kept.
2. **Fingerprints and matching.** Each peak gets a fingerprint: the L2-normalised mean
   spectrum of the peak bin ±1. Peaks are matched across batches by cosine similarity, with
   a one-to-one Hungarian assignment within 20 min and an adaptive similarity threshold.
   Each match is then refined to the best-matching scan within ±3 bins.
3. **Geometric filtering.** Outliers from a RANSAC straight-line fit (3-bin residual) are
   removed, and the longest subset in elution order is kept (longest increasing
   subsequence).
4. **Pooling.** Anchors from three batch-A samples matched to B[0] are combined (median
   B bin per A bin). Drift outliers (more than 1.5 s.d.) and anchors that imply an
   implausible local slope (outside 0.5–2) are then dropped.

The anchor count after every stage is reported (`gcmsalign.anchors`).

### ChromaWarpTransformer

`ChromaWarpTransformer` takes all N chromatograms of both batches at once, `[N, T = 200,
M = 1000]`. It predicts a warp per sample that maps a shared consensus time axis to that
sample's time axis.

- **Tokens.** Each bin's spectrum is projected to d = 128, with a sinusoidal position
  encoding and a learned batch (study) embedding.
- **Attention.** Layers alternate *local* attention, along time within a sample, with
  *global* attention, across samples at each time bin. There is no position encoding over
  samples, so their order does not matter.
- **Monotone warp with free ends.** Increments are δ(t) = softplus(u(t) + log(e − 1)),
  which is 1 when u = 0. They are summed from a per-sample start offset predicted by a
  second head. The warp is strictly increasing and neither end is pinned. Both heads are
  zero-initialised, so an untrained model is exactly the identity.
- **Resampling.** The warp is applied by linear interpolation, clamped to the run.

### Synthetic pretraining

Mini-datasets of 4–16 chromatograms are built from EI-MS library spectra:
- **Compounds.** About 30 compounds each, with peak widths σ ~ U(0.5, 1.5) bins.
- **Drift.** Per-compound jitter of ±4 bins, plus a batch offset of 5–25 bins (up to
  ±5.6 min).
- **Preprocessing.** Each chromatogram is square-rooted and L2-normalised per bin, exactly
  as the real data is.

The target warp is linear through the true peak positions and continues with slope 1 beyond
the outer peaks. The loss is the warp MSE plus a smoothness penalty, over 10,000 seeded
iterations.

### Test-time calibration

Calibration runs 500 Adam steps on two losses:
- **The exact anchor loss.** A compound at batch-A bin *r* and batch-B bin *q* must reach
  the same consensus bin: w_B(w̄_A⁻¹(*r*)) = *q*, where w̄_A is the mean batch-A warp.
- **A smoothness penalty** on the warp velocity, with weight 0.05.

The parameters with the lowest loss are kept. The setting is transductive: metrics are
computed over all A × B sample pairs, including those that supplied the anchors. The only
supervision is spectral similarity, never TIC correlation.

### Baselines

| Method | Description |
|---|---|
| Unaligned | No alignment |
| icoshift | 10 equal intervals, each shifted by the integer lag (±20 bins) that maximises cross-correlation |
| COW-TIC | Correlation optimised warping: 4 segments, interior nodes free within ±22 bins; maximises summed segment-wise TIC r, the evaluation metric itself |
| PCHIP (pooled anchors) | A monotone spline through exactly the WarpTransformer's anchors, continued with slope 1 beyond them; no network |

### Metrics

- **TIC r.** The mean Pearson r between aligned TICs over all A × B sample pairs. It is
  computed on the common acquisition window (5.0–45 min; earlier bins are empty in some
  runs), for both the normalised TIC and the raw TIC.
- **Held-out anchor error.** The retention-time error, in minutes, at an anchor that was
  left out of calibration. This is a compound-level check that doesn't depend on TIC r.
- **Within-batch ceiling.** The unaligned TIC r between samples of the same batch, as an
  upper reference.
- **Study silhouette.** Batch separation of per-m/z maximum projections. This is a
  secondary diagnostic: the projection is largely insensitive to retention time.
- **Significance.** Paired Wilcoxon signed-rank tests per batch-A sample, with Holm
  correction. The paper's tables are means ± s.d. over five calibration seeds.

## Results

The results are being regenerated. A code audit on 2026-10-11 found that the v1 pipeline:
- binned runs by scan index, although the batches start acquiring at different times
  (3.0 or 5.0 min);
- detected peaks on the normalised rather than the raw TIC;
- mixed two time axes;
- used an approximate anchor loss.

All of these are fixed and covered by tests. The tables will be added here after the full
rerun ([`run.md`](run.md)). The v1 numbers remain in the git history but should not be used.

## Testing and code quality

```bash
python3.11 -m pytest -m "not slow"     # unit tests, ~10 s
python3.11 -m pytest                   # + every step end to end on synthetic data, ~3–4 min
python3.11 -m coverage run -m pytest && python3.11 -m coverage report
python3.11 -m ruff check src scripts   # lint
python3.11 -m mypy                     # types
```

- **Size and coverage.** 252 tests, with about 93% branch coverage of `gcmsalign`.
- **What they check.** Exact warp identities, the exact anchor loss (including a
  `gradcheck`), recovery of known drifts on synthetic GC-MS data, and seeded
  reproducibility.
- **End to end.** Every step runs through its command line on a synthetic dataset.
- **Real data.** Tests marked `real` check the real data, and are skipped when it is
  absent.

## Limitations

- **One dataset.** The method is evaluated on a single fish-oil dataset across four
  batches. Generalisation to other matrices, instruments, column chemistries and analyte
  classes is untested.
- **Tuned pretraining.** The synthetic pretraining distribution is tuned to this
  dataset's drift range.
- **Few, early anchors.** Anchors are few (about 6–9 per pair) and come from the tallest
  raw-TIC peaks, which in this dataset elute in the first 30 minutes. Drift later in the
  run is extrapolated.
- **No independent RT check.** Compound identities are inferred from spectral matching.
  Retention indices from n-alkane standards would be a stronger, independent check.
